# 设计与项目总览

这页作为项目区主入口，用来集中展示我这几年做过的一些网页设计、视觉尝试和项目表达。

和“严格工程项目”相比，这里的内容更偏向：

- 页面设计
- Logo 设计
- 站点风格尝试
- 早期网页作品
- 工具实践

## 项目摘要

这部分内容主要来自我平时“边学边做”的积累。
它们不一定都很正式，但比较能反映我的审美方向、表达方式和把想法落成页面的过程。

## 代表内容

这是一个偏品牌感的小练习，重点不是复杂功能，而是图形识别度和简洁表达。

- 关注点：简洁、可识别、适合网络传播

## 5. 个人网站风格尝试

我也做过多种个人站点风格尝试，包括：

- 模仿优秀博客或展示页
- 尝试不同主题框架
- 调整首页布局和品牌视觉

例如这个阶段我参考过一些优秀的个人站点表达方式，用来练习自己的页面审美和结构组织能力。

## 适合以后继续补充的结构

如果你以后继续往这页加内容，建议每个项目都按这个顺序写：

1. 项目名称
2. 一句话介绍
3. 做这个内容的背景
4. 截图
5. 结果或感受
6. 链接或延伸阅读
