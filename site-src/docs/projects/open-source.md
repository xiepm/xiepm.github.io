# 开源项目推荐

这页用于整理那些值得长期关注、反复回看的开源项目和学习型资源。

我更偏向收藏两类内容：

- 能直接启发项目实现思路的资源
- 能帮助理解底层原理和工程结构的资源

## 推荐方向

### 1. Build Your Own X

这是我目前最推荐的一类资源。

它的价值不只是“给你一堆链接”，更重要的是它把很多复杂技术拆成了可以一步步重建的学习路径。

核心理念很适合做项目型学习：

> What I cannot create, I do not understand.

也就是：

- 如果不能亲手做出来，就很难说真正理解了它
- 想学深一点，最好的方式之一就是自己实现一遍

## 这个资源适合什么人

如果你属于下面几类人，这个资源会特别有用：

- 想把“看懂”升级为“会做”
- 想从教程学习走向项目实践
- 想了解系统、编译器、网络、数据库这类底层内容
- 想做更有技术含量的长期项目积累

## 我最推荐优先看的方向

下面这些方向最适合拿来做长期学习和项目沉淀。

### 3D Renderer

适合：

- 图形学入门
- 计算机视觉相关背景补充
- 训练空间理解和渲染思维

### BitTorrent Client

适合：

- 网络协议学习
- 文件传输机制理解
- 从协议到客户端实现的练习

### Database

适合：

- 存储系统基础
- 数据结构和索引理解
- 后端工程基础能力提升

### Docker

适合：

- 容器技术理解
- 工程部署思维建立
- 从“会用工具”走向“理解工具原理”

### Neural Network

适合：

- AI 学习者
- 想从调用框架走向理解模型基本结构的人
- 希望建立模型实现直觉的人

### Operating System

适合：

- 操作系统方向学习
- 计算机基础加深
- 长线技术成长

### Programming Language

适合：

- 编译原理兴趣方向
- 语言设计与解释器实现
- 对“代码如何被执行”有深入兴趣的人

### Search Engine

适合：

- 信息检索
- 索引和查询机制理解
- 搜索相关项目练习

### Shell

适合：

- 命令行工具理解
- Linux / 系统基础训练
- 适合作为第一个“自己造一个系统工具”的项目

### Web Browser / Web Server

适合：

- Web 基础原理
- 前后端协议理解
- 训练全链路思维

## 我的使用方式

我一般不会把这类资源当“清单网站”去扫，而是会这样用：

1. 先挑一个和当前学习方向最接近的主题
2. 看它的结构和教程分类
3. 选一个语言版本开始做
4. 把过程整理成自己的项目笔记
5. 把能沉淀的内容放回个人站

这样它就不只是“收藏夹”，而是会真的变成项目来源。

## 推荐起步顺序

如果想从容易上手的方向开始，我建议按这个顺序：

1. Shell
2. Command-Line Tool
3. Web Server
4. Search Engine
5. Database
6. Neural Network

如果你偏系统和底层，也可以试：

1. Operating System
2. Network Stack
3. Programming Language
