# AI 学习路线

这页作为第一篇真实的学习类文章，先不做成“零散收藏”，而是整理成一个可长期补充的 AI 学习入口。

当前最适合作为起点的公开参考是：

- [Datawhale 人工智能培养方案](https://datawhale.feishu.cn/docs/doccn0AOicI3LJ8RwhY0cuDPSOc)

## 这页的目标

我希望这里以后承担三个作用：

- 记录 AI 学习路线
- 放长期有效的资源入口
- 作为后续模型实践、工具体验和项目记录的总入口

## 我的 AI 学习结构

我会把 AI 方向大致分成这几层：

### 1. 数学基础

重点不是把所有数学重新学一遍，而是围绕 AI 真正会反复遇到的内容补基础。

建议优先关注：

- 线性代数
- 概率论与统计
- 微积分基础
- 优化方法的直觉

### 2. 编程与工程基础

AI 不只是模型知识，工程能力同样重要。

建议至少保证下面这些内容熟练：

- Python
- 数据处理基础
- 虚拟环境和依赖管理
- Git
- 基本实验记录习惯

### 3. 机器学习基础

这一层更适合当成“概念地基”。

重点包括：

- 监督学习
- 训练集 / 验证集 / 测试集
- 过拟合与欠拟合
- 常见模型与评估方式

### 4. 深度学习基础

这一层开始进入更典型的 AI 内容。

建议关注：

- 神经网络基本结构
- 前向传播与反向传播
- 损失函数
- 优化器
- 常见框架使用

### 5. 应用方向

等基础打稳以后，再按兴趣进入应用方向：

- 计算机视觉
- 自然语言处理
- 语音方向
- 多模态方向
- AI 工具与智能体应用

## 推荐的学习方式

我不太建议一开始就只盯着模型参数和论文术语，更推荐这样走：

1. 先建立整体地图
2. 用课程或培养方案补主干知识
3. 用小实验快速验证理解
4. 再进入具体方向做项目

这样比较容易避免“看了很多，但一直没有落地”。

## 现阶段最值得先做的内容

如果现在就要开始，我会优先做这几件事：

### 第一阶段

- 跑通 Python AI 基础环境
- 理解数据读取和预处理
- 了解机器学习与深度学习的区别

### 第二阶段

- 跑通一个简单分类任务
- 学会读取数据、训练、验证、保存模型
- 把实验过程写成自己的学习记录

### 第三阶段

- 进入一个具体方向，例如视觉或 NLP
- 结合一个真实项目开始持续积累
