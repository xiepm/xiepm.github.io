# 内容工作区

这个目录是给 `Xpm's Robot Lab` 后续维护用的内容工作区。

当前仓库里大部分页面已经是生成后的 `HTML`，历史目录很多，直接搬动旧目录会很容易造成链接失效。
所以这里采用更稳妥的方式：

- 旧目录继续保留，保证现有网页还能访问
- 新内容统一先放进 `content/`
- 后续你要新增、替换、整理素材时，只需要围绕这里维护

## 目录规则

- `home/`：首页要展示的精选文案、推荐内容、首页素材
- `projects/`：项目说明、项目图片、项目视频、项目封面
- `study/`：学习笔记、专题整理、课程内容、技术资料
- `message/`：留言页说明、互动区素材、引导文案
- `about/`：个人介绍、简历、头像、个人相关资料
- `assets/`：通用素材库

## 素材放置建议

- 文字：
  - 说明文档放到各栏目里的 `drafts/`
  - 固定文案放到各栏目里的 `snippets/`
- 图片：
  - 栏目图片放到各栏目里的 `images/`
  - 全站共用图片放到 `assets/images/`
- 视频：
  - 栏目视频放到各栏目里的 `videos/`
  - 全站共用视频放到 `assets/videos/`
- 其它附件：
  - PDF、压缩包、文档放到各栏目里的 `files/`

## 以后怎么维护

推荐你以后按这个流程操作：

1. 先把原始内容丢进 `content/` 对应栏目
2. 在该栏目下整理好文字、图片、视频
3. 再决定哪些内容需要同步到现有网页页面里

这样做的好处是：

- 不会碰乱现有站点结构
- 你能很快找到每类内容放哪里
- 以后如果要改成真正的源文件仓库，也能直接从这里迁移

## 当前建议映射

- 原 `develop/`、`Open-source/` 等偏作品内容，后续优先整理进 `content/projects/`
- 原 `Robotics/`、`AI/`、`Programming/`、`TOOLS/` 等学习内容，后续优先整理进 `content/study/`
- 原 `about/` 下个人资料，后续优先整理进 `content/about/`
- 首页精选图文，后续优先整理进 `content/home/`
